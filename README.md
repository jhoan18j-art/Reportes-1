Club Park Valet y Estacionamientos S.A. de C.V.
Sistema Inteligente de Control Operativo, Auditoría y Movilidad Masiva
📋 Descripción General
Sistema web y móvil desarrollado en Python (Streamlit) diseñado a la medida para Club Park Valet y Estacionamientos S.A. de C.V.. Está optimizado para soportar flujos masivos de operación de hasta 3,000 vehículos diarios, gestionando autenticación segura, registro multivista de automóviles, generación de boletos térmicos corporativos y reportes ejecutivos de rentabilidad.  
🚀 Características Principales
Autenticación Híbrida (QR por Sucursal y Supervisores):
Acceso rápido mediante escaneo de códigos QR o tokens específicos asignados a cada encargado de sucursal (15 a 20+ puntos operativos).
Perfiles gerenciales y de máxima jerarquía para el Contador Auditor y Supervisores Globales (Víctor Manuel y José de Jesús) con visibilidad completa de la red.
Registro Multivista (Blindaje Patrimonial):
Captura obligatoria de 4 fotografías por vehículo (Vista Frontal, Costado Izquierdo, Costado Derecho y Vista Trasera) optimizadas y comprimidas automáticamente para almacenamiento eficiente en la nube o servidor.  
Impresión Térmica Bluetooth (3 Secciones con Cortes):
Diseño exacto basado en el boleto físico corporativo.
Divide el ticket en tres partes mediante comandos de corte ESC/POS (GS V):
Boleto del Cliente: Con datos de tarifa, folio, marca, placas, color, entradas, salidas y apartados de custodia para objetos de valor (celulares, electrónicos) y exenciones de responsabilidad.
Boleto / Llavero: Control rápido con folio, placas y ubicación.
Contraseña / Parabrisas: Comprobante para colocar en el vehículo.
Conexión directa mediante Web Bluetooth API compatible con navegadores móviles en dispositivos Android.
Módulo de Reportes y Rentabilidad (Excel Oficial):
Análisis financiero en tiempo real, cálculo de ingresos por sucursal y volumen de operaciones.
Generación y descarga de libros profesionales de Excel (openpyxl) con formato corporativo, tanto globales como filtrados por sucursal.  
Auditoría, Alertas y WhatsApp:
Programación y control de Eventos Extraordinarios.
Bitácora de custodias y objetos de valor declarados.
Enlaces de comunicación directa y automatizada vía WhatsApp para alertas operativas.
